# Inventory Management System

A simple inventory management system built in Python using Object-Oriented Programming (OOP) principles.

## Features

- Add new products to inventory
- Update product information
- Delete products from inventory
- Track product quantities and suppliers
- Place customer orders
- Automatically update inventory levels after purchases

## Concepts Demonstrated

- Classes and Objects
- Constructors (__init__)
- Class Methods (@classmethod)
- Instance Methods
- Lists and Data Structures
- Encapsulation and State Management
- Basic Inventory and Order Processing Logic

## Project Structure

- Product class: manages inventory operations
- Order class: handles customer orders and inventory updates

## Learning Goals

This project was built to practice Python OOP fundamentals, including designing classes, managing shared class state, and implementing simple business logic.
